# 🧮 Calculator

Responsive calculator app that supports basic math operations like **addition**, **subtraction**, **multiplication**, **division**, and **percentage**. Built using HTML, CSS, and vanilla JavaScript.

🔗 **Live Demo:** [Calculator Preview](https://torrescam.github.io/Calculator/)

## 🛠️ Installation

1. **Clone the repository**:
   ```bash
   git@github.com:Torrescam/Calculator.git
   ```

## 💻 Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
